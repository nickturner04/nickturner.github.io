City Designer

City Designer City Designer City Designer

This is a Python program written for an assignment in May 2024

The program is a maya plugin made with python in two parts, the city designer and the generator. The designer allows the user to plot the roads of a city and serialise it into a text file. This can then be imported into maya to procedurally fill the layout with buildings. The designer is written with TKinter and the generator uses maya's Python API.
